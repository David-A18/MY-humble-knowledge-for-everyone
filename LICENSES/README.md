Scripts, workflow files, configuration, issue forms, executable examples,

`knowledge/`. Code blocks in documentation are MIT-licensed to the extent they
are protectable.

## Attribution

Reuse of CC BY 4.0 material must provide appropriate credit, a link to the license, and an indication of changes. Keep any page-level source citations when they support a technical claim.

External documentation is cited for evidence; a citation does not grant permission to republish that source. Contributors must write original summaries and respect the terms of any quoted, embedded, or copied material.
