# Examples

Runnable lab files that pages in the [knowledge base](../knowledge/index.md) link
to. The knowledge bundle itself is Markdown only; the code, manifests, and data
that a lab runs live here, in a folder that mirrors the page's topic path.

Every file must be readable text in an allowed format. Binaries, archives,
media, and shell scripts are rejected; see the
[content and security policy](../governance/content-policy.md).
