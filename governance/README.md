# Governance

Policies, review records, and plans that keep the knowledge base safe and
reliable. Nothing here is reader-facing knowledge; that lives in the
[knowledge bundle](../knowledge/index.md).

## Policies

| Document | Use it for |
| --- | --- |
| [Content and security policy](content-policy.md) | Allowed files, safe Markdown and links, moderation, sanctions, and required repository settings. |
| [News editorial policy](news-editorial-policy.md) | Scope, sourcing, neutrality, and corrections for news briefs. |
| `policy/` lists | The reviewed [link domain allowlist](policy/allowed-link-domains.txt), [approved URL prefixes](policy/allowed-link-prefixes.txt), hashed [blocked terms](policy/blocked-terms.sha256), and [moderation exceptions](policy/moderation-exceptions.txt). |
