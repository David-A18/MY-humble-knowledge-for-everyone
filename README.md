# My humble knowledge for everyone

Practical technology knowledge, explained simply, for people and AI agents. The
curated corpus is an [Open Knowledge Format v0.2 bundle](knowledge/index.md):
portable Markdown with structured metadata, clear navigation, and visible trust
status. A [news section](knowledge/news/index.md) adds dated briefs on AI,
technology, and the economy.

Today most guides cover cloud and platform engineering: Kubernetes, AWS,
Terraform, Git, FinOps, and retrieval-augmented generation. See the
[roadmap](ROADMAP.md) for what comes next, including the public website.
