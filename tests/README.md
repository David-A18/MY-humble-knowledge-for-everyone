# Knowledge-quality test data

- [Retrieval cases](retrieval-cases.yaml) - Human task questions with their
  expected concept paths and evidence identifiers.
- [Bootstrap grid preview](bootstrap-grid-5.3.8.html) - Small local page used
  to render the responsive-grid screenshots in the teaching article. It pins
  Bootstrap CSS 5.3.8 and does not need Bootstrap JavaScript.
- [Offline Node bootstrapping demo](bootstrapping-node-demo/README.md) - Local
  package and lockfile used to check a missing import before installation
  and a successful import after a clean, offline install.

The cases test catalog integrity now. They form the golden set for an actual
retrieval engine when one is introduced.
