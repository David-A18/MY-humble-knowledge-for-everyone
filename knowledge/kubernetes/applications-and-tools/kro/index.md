# kro: Kube Resource Orchestrator

Build a reusable Kubernetes API from a graph of ordinary resources. Examples target kro 0.9.4 and its v1alpha1 ResourceGraphDefinition API; do not mix them with unreleased documentation.

Read in order, or choose a task from the table.
