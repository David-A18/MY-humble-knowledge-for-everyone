# Why this example has a separate guide

This folder is a teaching example inside the repository's `knowledge/` bundle.
It shows what an OKF directory can look like; its sample records are drafts,
not evidence of a real system or a separately validated production bundle.

The [example index](index.md) lists the pages. This file is an ordinary
concept whose ID ends in `readme-concept`. OKF reserves only `index.md`
and `log.md`; this file has no reserved role. Only `knowledge/index.md`
declares the OKF version.
