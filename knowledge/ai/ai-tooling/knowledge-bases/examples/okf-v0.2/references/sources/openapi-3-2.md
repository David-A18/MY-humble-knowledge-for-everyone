# OpenAPI Specification v3.2.0

An OpenAPI document describes an HTTP API's paths, operations, parameters,
request bodies, responses, and security schemes. This specification explains
the format used to express those facts. To know what a **particular** API
accepts, inspect that API's own OpenAPI document; the standard alone cannot
tell you its endpoint names.
