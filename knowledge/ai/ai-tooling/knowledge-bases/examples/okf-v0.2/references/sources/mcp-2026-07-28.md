# Model Context Protocol 2026-07-28

This versioned MCP page describes how a server lists and exposes tools.
It can help you design a knowledge search or fetch tool; those names and
budgets are choices made by the server author. MCP does not decide which
knowledge page is correct,
set a retrieval budget, or grant access to a private document.
