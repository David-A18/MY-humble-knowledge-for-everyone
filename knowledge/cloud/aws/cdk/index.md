# AWS CDK v2

Define AWS infrastructure in a programming language, synthesize CloudFormation, and review deployment changes. The paired labs use equivalent TypeScript and Python stacks.

## Learning path

Read in order, or choose a task from the table.

| Guide | Use it for |

| [TypeScript and Python labs](typescript-and-python-labs.md) | Build the same protected S3 stack in both languages. |
| [Assertions and CI](assertions-and-ci.md) | Test generated infrastructure and compare language outputs. |
| [Deployment and troubleshooting](deployment-and-troubleshooting.md) | Bootstrap, review, deploy, recover, and retain data. |
