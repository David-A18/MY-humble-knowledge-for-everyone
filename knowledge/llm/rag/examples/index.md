# RAG example files

- `rag.py`: curated ingestion, FTS5/BM25 search with OKF trust metadata, evidence-sufficiency checks, and optional local generation.
- `test_rag.py`: exclusion, coverage, rebuild, quoting, no-evidence, citation, trust metadata, and real-corpus smoke tests.

Use a disposable database outside Git. No third-party Python dependencies are required.
