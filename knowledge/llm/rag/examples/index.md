# RAG example files

- `rag.py`: curated ingestion, FTS5/BM25 search, and optional local generation.
- `test_rag.py`: exclusion, rebuild, quoting, no-evidence, citation, and real-corpus smoke tests.

Use a disposable database outside Git. No third-party Python dependencies are required.
